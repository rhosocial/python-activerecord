State the ownership rule the branch settled: a family lives where the divergence says it lives, and `extra` is neither a home for another engine's facts nor a way to widen a signature. A capability declared by `supports_*` must have a non-empty formatter, and a CLI type must name a predicate the dialect actually declares, so "answerable but unaskable" and "unanswerable but offered" both stay impossible. SQLite consumes the new families whole, reports exact row counts while naming the source it read, offers the three data families through `introspect`, and answers `False` for DDL extraction until a formatter exists instead of half-promising. A query whose conditions leave part of the caller-supplied key unconstrained now says so -- on a table partitioned by that column it was scanning every partition silently. A missing caller-supplied key field is named at INSERT time instead of failing on the server. Documentation splits the introspection chapter into capabilities, operations and data profiles in both languages.
