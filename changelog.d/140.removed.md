**Breaking:** model declarations moved from class-body dunders onto overridable classmethod accessors. `__table_name__`, `__schema_name__`, `__primary_key__`, `__pk_auto_generated__`, the soft-delete/timestamp/version locators (`__deleted_at_field__`, `__created_at_field__`, `__updated_at_field__`, `__version_field__`, `__version_increment_by__`) and `__read_only__` no longer declare anything: declare by overriding `table_name()`, `schema_name()`, `primary_key()`, `pk_auto_generated()`, the matching locator method or `read_only()`. `table_name()` has no default, so a model that declares no table fails with `NotImplementedError` at the first read instead of carrying a `None` name into a statement. Accessor defaults read no dunder at all, and the declaration dunders were removed, so there is no compatibility path: this is a pre-1.0 migration made once and completely. `__partition_key__` remains a valid direct declaration for introspected models, mutually exclusive with `UsePartitionKey()` annotations.
