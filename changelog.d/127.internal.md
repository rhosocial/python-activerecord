The S3 expression-layer refactor: the introspection expressions were renamed to `*Statement`, constraint nodes were split into clause and branch levels, the value / function / predicate families took the names in the naming spec, the wildcard node was split by grammar position per spec 4.10, and `IntrospectionCache` became an injectable component the manager owns rather than a hidden attribute. The test toolchain is pinned below pytest 9.2, which removed the private `_nodeid` attribute pytest-benchmark still reads and changed the suite's behaviour under `-n auto`; a dependency that arrives new every morning turned a green matrix into a coin toss.
