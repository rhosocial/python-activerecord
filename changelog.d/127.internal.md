The S3 expression-layer refactor: the introspection expressions were renamed to `*Statement`, constraint nodes were split into clause and branch levels, the value / function / predicate families took the names in the naming spec, the wildcard node was split by grammar position per spec 4.10, and `IntrospectionCache` became an injectable component the manager owns rather than a hidden attribute. Rather than let the pin rot, the test toolchain runs pytest 9.2 and later: 9.2 moved a node's identifier into a structured `NodeId`, which broke pytest-benchmark's read of the private `node._nodeid` and silently unhooked the `--dist=loadgroup` grouping pytest-xdist writes to the same slot. Both are shimmed in the test suite's `pytest_compat` plugin, loaded by entry point wherever the suite is installed, so the matrix keeps proving the library on the pytest everyone is being offered instead of on the one it was last green with.
