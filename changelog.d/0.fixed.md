Added `supports_microsecond_timestamp()` and `supports_explain_plan()` dialect capability hooks so backends without microsecond precision or an EXPLAIN statement (e.g. Firebird) can advertise that and let tests adapt.

Made `WorkerPool.submit()` readiness wait configurable via the `ready_timeout` constructor parameter (default 30s) so slow-spawning `spawn` worker processes on backends like Firebird no longer fail with a 5s timeout.

Improved `LeastTasksStrategy` to prefer waiting for a freshly starting worker instead of queuing all tasks onto the single ready-but-busy worker, keeping queues balanced on slow-spawning backends.

Fixed relation/derived bridge files to import the correctly named testsuite modules (`test_relation_derived_field*`).

Decoupled migration schema-diff resolution from concrete backend imports: the core no longer hardcodes `impl.mysql`/`impl.postgres`/`impl.sqlserver` differ imports in the migration runners. Differs are now resolved through the dependency-inversion hook `dialect.create_schema_differ()`, so the core never references external backend packages and new backends (e.g. Oracle, MariaDB) need no core changes.
