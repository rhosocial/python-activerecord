`one()` now honours rows added by a `JOIN`; `in_()` / `not_in()` accept symmetric
input shapes; `AsyncActiveQuery` gained `to_query_expression()`; generated columns
are excluded from INSERT and UPDATE payloads. SQLite reported support for
`CREATE OR REPLACE VIEW`, which it does not have — `replace=True` silently
rendered `CREATE VIEW IF NOT EXISTS` and left the old definition in place, and now
raises instead. Schema snapshots no longer model views as tables.
