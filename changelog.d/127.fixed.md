A disjunction nested inside a conjunction keeps its brackets when a logical predicate renders, a SET DEFAULT value reaches the ALTER statement, a type modifier is judged where it is rendered rather than where it is declared, `UseColumnType` resolves `ColumnBase` at runtime, and escaping goes through the dialect instead of the base class.

`pool.transaction()` no longer reports a failed rollback instead of the error that caused it: when the body raised and the rollback then failed (a transaction already ended by the failing statement, a lost connection), the `TransactionError` from the rollback replaced the original exception, so callers saw "No active transaction to rollback" for what was, in the observed case, a duplicate-key `IntegrityError`. The rollback failure is now logged and the original exception propagates, in both the sync and async pools.
