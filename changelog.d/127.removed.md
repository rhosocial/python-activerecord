Remove the unused `JoinType` enum and the never-read `join_clauses` query attribute. `JoinClause` takes `join_type` as a plain SQL string, yet its own docstring examples passed `JoinType.INNER` / `JoinType.LEFT`, which fails at runtime with `AttributeError: 'JoinType' object has no attribute 'upper'`; the examples now use strings and the dead enum is gone. `join_clauses` was declared on the `IQueryBuilding` protocol and initialised in four places but read nowhere, in this repository or any sibling backend.
