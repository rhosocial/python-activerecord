# Testing framework for unit and integration tests
# Core framework for running test suites and fixtures
#
# Pinned below 9.2 on purpose. 9.2 removed the private ``node._nodeid`` alias
# that pytest-benchmark 5.3.0 still reads, so every benchmark test errored at
# setup with ``'Function' object has no attribute '_nodeid'``; the same release
# also changed how the suite behaves under ``-n auto``, which turned 14 shared-
# state tests (worker hooks, the deep named-series CLI) red on a day when no
# line of the library had changed. A toolchain that arrives new every morning
# turns a green matrix into a coin toss, so the pin holds it at the version CI
# was last green on, and a bump is a deliberate act with a run to prove it.

pytest-asyncio
